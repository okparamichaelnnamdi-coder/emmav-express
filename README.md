# EMMAV Express

A responsive delivery and logistics business website created as an individual HTML, CSS and JavaScript web-development project.

## Business concept
- **Name:** EMMAV Express
- **Slogan:** Delivering with speed, care and trust.
- **Type:** General delivery and logistics
- **Base:** Abakaliki, Ebonyi State, Nigeria
- **Coverage concept:** Across Nigeria
- **Hours shown:** 24 hours, every day
- **Customers:** Individuals and business partners
- **Services:** Parcel delivery, same-day delivery, food delivery and grocery delivery
- **Pricing concept:** Based on distance and package size

## Project files
- `index.html` — page structure and content, using semantic HTML sections and forms.
- `styles.css` — external stylesheet, typography, colours, spacing, box model, Flexbox/Grid layouts and responsive media queries.
- `script.js` — mobile navigation, sample tracking, form validation feedback, booking reference generation and pricing estimate.
- `README.md` — project information and instructions.

## Features
- Home, About, Services, Tracking, Booking, Business Partnerships, Pricing, FAQ and Contact sections.
- Four service cards.
- Booking form with sender/receiver details and required-field validation.
- Sample tracking timeline (try `EMX-2048`).
- Partnership enquiry form.
- Illustrative distance/package-size pricing calculator.
- Contact form with full name, email, subject and message validation.
- Responsive navigation and layouts for desktop, tablet and mobile.

## Run locally
1. Extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension if installed.

## GitHub upload
Create a **public** repository named `emmav-express`, then upload the four project files (`index.html`, `styles.css`, `script.js`, `README.md`) to the repository root. Commit the changes.

## Deployment
The assignment requires a public live website as well as the GitHub repository. One simple option is Netlify:
1. Sign in to Netlify.
2. Choose Add new site / Import an existing project.
3. Connect GitHub and select `emmav-express`, or use the manual deploy option and upload the project folder.
4. Wait for deployment and copy the public site URL.

## Important demonstration limitations
This is a front-end school-project demonstration. The booking, tracking, partnership and contact features do **not** connect to a real dispatch operation, database, courier fleet, map, payment gateway, SMS or email service. Forms validate in the browser and show sample feedback only; they do not transmit or store submitted data. Tracking shows a sample timeline. Prices are illustrative, not confirmed business rates. Do not enter real or sensitive customer information into the demo.
